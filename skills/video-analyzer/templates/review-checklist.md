# Review checklist

Record pass / fail / not checked with timestamps and evidence. Do not turn an unchecked box into a claimed pass.

## Performance

- [ ] Exact intended words, no unintended repetitions
- [ ] Face, hands, expression and gaze are convincing through the full take
- [ ] Requested action occurs with a visible cause and result
- [ ] No unwanted generated text or music
- [ ] Speech, mouth movement and picture cuts remain aligned

## Screen and graphics

- [ ] Exact UI text and coherent interaction states
- [ ] Insert follows phone corners through the hardest motion
- [ ] Hand/foreground stays in front; no old-UI patch under captions
- [ ] Blur, illumination and edges match the footage
- [ ] Captions/diagrams legible at delivery size
- [ ] A reconstruction is identified accurately

## Sound and edit

- [ ] Full intended app replies and dialogue tails preserved
- [ ] No host narration covers a listening comparison
- [ ] Adjacent loudness matched and transitions heard at natural speed
- [ ] No unapproved speed changes or stretched speech
- [ ] Source-to-final ranges and endpoints reconciled
- [ ] Full export watched/listened continuously

## Delivery

- [ ] Export decodes; size, frame rate, frame count and audio format recorded
- [ ] Editable sources and reproduction commands included
- [ ] Actual costs separated from estimates; model differences labeled
- [ ] Known defects and subjective review needs disclosed
- [ ] User acceptance recorded separately from technical completion
