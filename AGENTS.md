# Working in this kit

This is a public resource kit. Keep personal footage, downloaded reference clips, voice samples, `.env` files, signed upload URLs and provider receipts out of its public source tree. Create a separate working directory for each real production.

For an ad task, read `skills/video-analyzer/SKILL.md`. For a filmed-screen composite, also read `skills/blender-video-editing/SKILL.md`. Use the installed official Remotion skills for Remotion code. Do not treat these setup documents as permission to install software, connect an account or spend credits without the user's relevant request.

Keep the user's script and approved outputs. Make new versions for experiments. Ask for the initial generation batch with its exact jobs and cap; reuse existing authorization within that scope. Record actual outcomes and costs separately from plans. If retries are allowed, diagnose the failure, make a targeted correction and stay within their limit. Never purchase or top up credits without an explicit user instruction.

When using multiple agents, assign one owner per output directory and one assembly owner. Follow `guides/parallel-editing.md`. An owner assignment is not evidence that a worker is currently running.
